# 📊 Sales Insights Dashboard – FMCG Industry

## 🚀 Project Overview
This project focuses on analyzing FMCG sales data to uncover meaningful business insights and support data-driven decision-making using Excel, SQL, and Power BI.

The dashboard helps analyze:
- Revenue trends
- Year-over-Year (YoY) growth
- Top-performing customers and markets
- Quarterly sales performance
- Customer segmentation

---

## 🛠️ Tools & Technologies Used
- Excel
- SQL
- Power BI
- DAX
- Data Cleaning & Transformation
- Data Visualization

---

## 📈 Key Features
- Interactive Power BI Dashboard
- Year & Month-wise Revenue Trends
- YoY Growth Analysis
- Customer & Market Performance Analysis
- Quarterly Sales Comparison
- USD to INR Currency Filtering
- Business KPI Tracking
